# 指尖小蛇 · Cursor Snake

一个**单文件、零依赖**的网页小游戏：鼠标或手指移到哪里，小蛇就跟着跑到哪里，碰到食物就吃掉、变长、加分。小朋友也会喜欢的糖果感画风，内置 4 套主题、3D 立体观感、点击/吃到反馈和 WebAudio 合成音效。

- 单文件：`index.html`（内联 CSS / JS，无 CDN、无外链字体图片音频、无构建步骤）
- 直接双击用浏览器打开即可玩（`file://` 也能跑）

## 怎么玩

1. 双击 `index.html`，点「开始玩」。
2. **移动鼠标 / 手指**，小蛇的头会平滑地追过去，身体自然弯曲跟随。
3. 蛇头碰到食物 → 食物消失、+分、身体变长（越吃越长）。短时间内连续吃会累积**连击**，加分更多、音效音高更高。
4. 点击 / 轻触屏幕任意位置 → 涟漪 + 粒子爆发 + 轻微震屏 + 点击音效（手机还有触感震动）。
5. 顶部显示 **分数 / 长度 / 最高分**（最高分自动存进浏览器 localStorage）。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `空格` | 开始 / 暂停继续 |
| `M` | 静音开关 |
| `F` | 全屏 |
| `1` `2` `3` `4` | 切换糖果乐园 / 太空探险 / 森林乐园 / 海底世界 |

## 主题

一键切换，带闪光过渡和专属音阶，选择会被记住：

| 主题 | 风格 | 食物 |
| --- | --- | --- |
| 🍬 糖果乐园 candy | 粉橘糖果色 | 糖果、棒棒糖、甜甜圈、纸杯蛋糕 |
| 🚀 太空探险 space | 深空紫 + 星光 | 星星、火箭、行星 |
| 🌳 森林乐园 forest | 清新草绿 | 苹果、草莓、蘑菇、栗子 |
| 🐠 海底世界 ocean | 海蓝气泡 | 小鱼、河豚、螃蟹、贝壳 |

## 3D 与性能

- 「🧊 3D」按钮可开关立体效果：透视地面网格 + 球体径向高光/暗部 + 落地投影 + 指针轻微视差。关掉后是干净的平面糖果风。
- 渲染用 `requestAnimationFrame` + 时间步进；DPR 上限 2；蛇身段数上限 220（超过仍照常加分）；粒子/涟漪/飘字全部对象池化；窗口尺寸变化自适应。

## 音效

全部由 WebAudio 实时合成，**不加载任何外部音频文件**：吃到（音高随连击上升）、里程碑和弦、点击 pop、切主题 chime、开始提示音；静音状态持久化。音频在首次用户交互后才初始化（遵循浏览器自动播放策略）。

## URL 参数（便于调试 / 自动化测试）

| 参数 | 说明 |
| --- | --- |
| `?theme=candy\|space\|forest\|ocean` | 指定初始主题 |
| `?mute=1` | 初始静音 |
| `?3d=0` | 关闭 3D |
| `?seed=123` | 固定食物随机序列（截图可复现） |
| `?autostart=1` | 跳过开场遮罩直接开玩 |
| `?demo=1` | 演示模式：指针自动绕圈并自动进食，方便截图 |
| `?fresh=1` | 忽略本地存档（分数/主题/静音/3D 用默认值），截图复现用 |
| `?frames=240` | 启动后先同步推进 N 帧再定格渲染（配合 seed 得到确定画面） |
| `?selftest=1` | 运行脚本化自测，结果写入页面 `<pre id="selftest-output">` |

自测示例（命令行用 Edge / Chrome 无头模式）：

```
msedge --headless=new --disable-gpu --virtual-time-budget=4000 --dump-dom "file:///.../index.html?selftest=1"
```

最后一行为 `SELFTEST: PASS n/n` 即全部通过。

## 给 QA 的稳定性钩子

页面元素 id 固定：`canvas#game`、`#hud-score`、`#hud-len`、`#hud-best`、`#theme-buttons`、`#btn-3d`、`#btn-sound`、`#btn-fullscreen`、`#selftest-output`；当前主题写在 `<body data-theme="...">`，3D/静音状态写在 `body[data-d3]` / `body[data-muted]`。
